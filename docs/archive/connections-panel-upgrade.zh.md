## 当前状态 vs AgentTerm 参照

| 功能区 | 我们现在 | AgentTerm | 差距 |
|---|---|---|---|
| **操作栏** | SSH/Telnet Tab + 保存/连接/取消按钮 | 连接按钮(绿色) + 协议 Tab + **收藏按钮** | 无收藏、无绿色连接按钮、无 Serial Tab |
| **连接表单** | 名称/主机/端口/用户名/密码/密钥/备注 | 同 + **newline/换行** + **localEcho/回显** + **握手超时** + **密码可见切换** + **高级折叠** | 缺换行/回显/高级折叠/密码可见 |
| **Telnet 表单** | 主机/端口/用户名(选填)/密码(选填) | 同 + **模式切换(Telnet/Raw TCP)** + **本地地址** + **自动登录**(账号/密码/提示正则/超时/延迟) | 缺模式切换、自动登录 |
| **Serial 表单** | 没做(MVP 后扩展项) | 完整(COM枚举/波特率/数据位/校验/停止位/流控/DTR/RTS/自动重连) | 完全缺失 |
| **会话列表** | 卡片(协议/名称/状态/✎编辑/✕删除) | 协议图标 + 名称 + **目标标签** + 状态圆点 + **未读标记** + **右键菜单**(置顶/重命名/断开/重连/移除) + **排序** | 缺未读标记、右键菜单、排序、置顶 |
| **收藏区** | 无(只有"最近连接"列表) | **收藏集分组** + 导入/导出 CSV/JSON + 搜索 + 2000 条上限 | 完全缺失 |
| **最近连接** | 有(卡片列表) | 有(可折叠 + hover 移除记录) | 缺折叠、hover 移除 |
| **密码安全** | 明文 JSON(0600) | Windows 凭据管理器(DPAPI) | 差距大 |
| **SSH host key** | 接受任意 | 首次确认 + known-hosts.json | 差距大 |
| **SFTP** | 无 | 连接成功后底部出现远端文件浏览器 | 完全缺失 |

## 按优先级分批

### 第一批：体验提升（改动小、收益大）

| # | 功能 | 做什么 | 难度 |
|---|---|---|---|
| 1 | **密码可见切换** | 密码输入框右侧加眼睛图标，点击切换 type=password/text | ⭐ 简单 |
| 2 | **连接表单高级折叠** | newline(换行 LF/CR/CRLF) + localEcho(回显开关) 折叠在"连接选项"下 | ⭐⭐ 中 |
| 3 | **会话未读标记** | 终端有新输出时会话条目出现蓝色小圆点；点击后消失 | ⭐⭐ 中 |
| 4 | **最近连接 hover 移除** | hover 显示"移除记录"按钮 | ⭐ 简单 |
| 5 | **会话右键菜单** | 右键会话→置顶/重命名(行内编辑)/断开/重连/移除 | ⭐⭐⭐ 中高 |
| 6 | **会话排序** | 已连接排最前 + 置顶在最前 | ⭐⭐ 中 |

### 第二批：功能扩展（中等工程量）

| # | 功能 | 做什么 | 难度 |
|---|---|---|---|
| 7 | **收藏功能** | 星形按钮收藏当前配置；收藏集分组(创建/命名)；点击回填表单 | ⭐⭐⭐ 中高 |
| 8 | **Telnet 模式切换** | Telnet / Raw TCP 双态；Raw TCP 端口默认 5000 | ⭐⭐ 中 |
| 9 | **Telnet 自动登录** | 登录模式(account/password/accountPassword) + 账号 + 密码 + 提示正则 + 超时/延迟 | ⭐⭐⭐⭐ 高 |
| 10 | **SSH 握手超时** | 下拉选择 30/60/120/180 秒 | ⭐ 简单 |
| 11 | **会话信息弹窗** | 点击会话名→弹窗显示协议/状态/换行/回显/会话ID(可复制) | ⭐⭐ 中 |
| 12 | **导入/导出** | CSV/JSON 批量导入连接配置 + 导出空白模板 | ⭐⭐⭐ 中高 |

### 第三批：安全 + 高级（工程量大、后续迭代）

| # | 功能 | 做什么 | 难度 |
|---|---|---|---|
| 13 | **密码安全** | 接 DSH `ctx.credentials` 服务；不再明文存 JSON | ⭐⭐⭐⭐ 高 |
| 14 | **SSH host key 确认** | 首次连接弹指纹比对；known-hosts.json 存储 | ⭐⭐⭐ 中高 |
| 15 | **Serial 表单** | COM 枚举 + 波特率/数据位/校验/停止位/流控/DTR/RTS + 自动重连 | ⭐⭐⭐⭐⭐ 很高(需 serialport 库) |
| 16 | **SFTP 文件浏览器** | SSH 连接成功后底部出现远端文件管理 | ⭐⭐⭐⭐⭐ 很高 |
| 17 | **搜索** | 多关键词搜索收藏（名称/协议/主机/用户名/端口/集名） | ⭐⭐ 中 |

## 建议执行顺序

1. **第一批全做**（1-6）——改动小、体验提升明显，半天到一天
2. **第二批选做**——按你的实际需求挑（比如 Telnet 自动登录如果你的设备需要登录，就做 8+9）
3. **第三批后续**——Serial 和 SFTP 是大工程，单独排期；密码安全和 host key 确认真机联调前必须做

## 不建议照搬的

- **Windows 凭据管理器(DPAPI)**：我们是 DSH 插件（跨平台），不该用 Windows 专属 API。改用 DSH 的 `ctx.credentials` 服务（跨平台）。
- **Serial Tab 放在协议 Tab 里**：AgentTerm 是独立工具所以放一起。我们串口是后续扩展项，可以等做了再加 Tab。
- **SFTP**：AgentTerm 有，但我们的方案明确 MVP 不做 SFTP。后续看需求。
