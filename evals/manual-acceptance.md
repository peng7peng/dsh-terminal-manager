# 人工验收清单

本文件是**唯一**的人工验收清单（原 `docs/test-plan.zh.md` 的脚手架指令已随测试补全完成而废弃，重复项并入本页）。照着逐条跑，每条勾上。跑完 = MVP 全功能人工验证通过。

## 前置准备

```sh
# 1. 起两台模拟设备
cd /d/myProject/dsh/dsh-terminal-manager
node scripts/mock-device.mjs 2323 &
node scripts/mock-device.mjs 2324 &

# 2. 起 DSH
cd /d/myProject/dsh/deepseek-harness
pnpm dsh --profile tm-dev --port 4580 --no-open &
# 浏览器开 http://127.0.0.1:4580，硬刷新（Ctrl+F5）加载最新 client.js
```

## 组一：配置管理

### ☐ S1 新建连接（保存）
- **操作**：点侧边栏底部「🖥️ 终端管理」→ 工作区打开 → 右侧「连接」面板 → 协议选 **Telnet** → 填 名称`mock-1`、主机`127.0.0.1`、端口`2323` → 点「保存」
- **预期**：不报错；「收藏」出现 mock-1

### ☐ S1-临时连接（不入库）
- **操作**：不点保存，直接点「连接」按钮
- **预期**：终端窗格出现，显示横幅 `Mock Router :2323`

### ☐ S12 编辑连接
- **操作**：点「最近连接」里的 mock-1 卡片 → 表单回填 → 改名称为 `mock-1-renamed` → 点「保存」
- **预期**：列表里名字变成 mock-1-renamed
- 注：编辑后想取消，点「取消」按钮（已加）

### ☐ S12 删除连接
- **操作**：右键 mock-1 卡片 → 删除
- **预期**：从列表消失

## 组三：手动操作

### ☐ S4 手动敲命令
- **操作**：在某个终端窗格里直接敲 `show version` 回车
- **预期**：能看到自己敲的字（设备回显）；回车后显示 `MockOS Version 1.0.4`
- 注：退格在输入行空了之后不再删提示符（已修）

### ☐ S5 广播到全部
- **操作**：底部广播栏（两行布局）输入 `show version` → 目标选「全部」→ 点「发送」
- **预期**：两个终端同时回显命令 + 版本输出

### ☐ S6 广播到部分
- **操作**：取消选一个芯片（只留一个目标）→ 发送
- **预期**：只有选中的那台回显

## 组四：AI 自动化（核心价值）

### ☐ S7 AI 单机测试
- **操作**：在聊天框发：`连上 127.0.0.1:2323 跑 show version 告诉我结果`
- **预期**：AI 调 tm_connect + tm_send，回复含 `MockOS Version 1.0.4`

### ☐ S10 人机共视
- **操作**：S7 跑的时候，同时看终端工作区
- **预期**：AI 连的会话出现在网格里，能看到设备回显
- 已知限制：AI 敲命令的「击键过程」不一定可见（取决于设备回显/localEcho，待办）

### ☐ S8 AI 批量测试
- **操作**：发：`连上 127.0.0.1:2323 和 2324，都跑 show version，汇总`
- **预期**：AI 用 tm_send_all 或两次 tm_send，汇报两台版本

### ☐ S9 AI 读现场
- **操作**：发：`连上 127.0.0.1:2323，告诉我当前屏幕显示什么`
- **预期**：AI 调 tm_read，描述横幅 `Mock Router`

## 组五：异常

### ☐ S11 地址不通
- **操作**：新建连接 主机`127.0.0.1` 端口`9999` → 点「连接」
- **预期**：报错（HOST_UNREACHABLE 或 CONN_TIMEOUT），不卡死

### ☐ S11 设备掉线
- **操作**：连上 2323 → 在终端里敲 `exit`（模拟设备会断开）
- **预期**：终端窗格消失/标记断开；状态点变灰

### ☐ S11 命令守卫（AI 路径）
- **操作**：发：`连上 127.0.0.1:2323 跑 rm -rf /`
- **预期**：AI 调 tm_send 被拦（COMMAND_BLOCKED），AI 告诉你命令被安全策略拦截

## 组七：九月迭代——本地文件面板 / 浮动编辑器 / TC 脚本执行（分支 `feat/sep-s1-files`）

> 先跑自动化：在插件目录 `pnpm build` 然后 `pnpm test`，应看到 **275 项全绿**；这一步不过就不用往下点了。

### 前置准备（比组一多三样）

1. **建一个测试目录**，比如 `D:\tc-test`，里面放三个文件（内容照抄）：

   `case1.txt`（TC 脚本；`##>0` 表示后面的命令发给 0 号终端，`##>01` 表示发给 0 号和 1 号）：
   ```
   [基础信息]
   ##>0
   show version
   show ip interface brief
   ##>01
   ##间隔1s再发
   show clock
   [接口检查]
   ##>1
   show interfaces
   ###echo 可发送注释
   ##>5
   show run
   ```

   `check.md`：
   ```
   # 验证清单
   - show version
   - show clock
   ```

   `a.py`：随便一行 `print(1)`。

2. 起两台模拟设备 `mock-device.mjs 2323` 和 `2324`，起 DSH（同组一）；浏览器硬刷新。
3. 连上两台：收藏里点 `mock-1`（2323）和 `mock-2`（2324），确认两个终端窗格都在线。

---

### ☐ F1 文件面板收起条
- **操作**：看工作区中间列最底下（广播栏下方）
- **预期**：一行「📁 本地文件」+ 当前根目录路径；点一下展开、再点收起；刷新页面后仍记得展开状态

### ☐ F2 换根目录
- **操作**：展开面板 → 点「换目录」→ 上面的输入框里输入 `D:\tc-test` 回车 → 点「选择此目录」
- **预期**：弹出提示「本地根目录已切换到 D:\tc-test」；列表出现 case1.txt / check.md / a.py；面包屑第一段显示 `tc-test`
- **附加**：再点「换目录」输入一个不存在的路径回车 → 红字报「目录不存在」，不崩

### ☐ F3 进目录、上一级、面包屑
- **操作**：在 `D:\tc-test` 下建个子目录 `sub` → 点「刷新」→ 双击 sub 进入 → 点「上一级」回来 → 再进入后点面包屑的 `tc-test`
- **预期**：三种方式都能回到根；在根时「上一级」按钮是灰的

### ☐ F4 双击打开文件
- **操作**：双击 `case1.txt`
- **预期**：屏幕下方弹出浮动编辑器，标签写 case1.txt，左侧有行号，内容和文件一致；底栏显示路径和大小

### ☐ F5 编辑与保存
- **操作**：在编辑器里随便加一行 → 看标签 → 按 Ctrl+S（或点底栏「保存」）→ 用记事本打开 case1.txt 核对
- **预期**：改动后标签出现黄点、「保存」变可点；保存后黄点消失、提示「已保存 case1.txt」；记事本里能看到新加的行。**测完把加的行删掉再保存**，后面的用例要用原始脚本

### ☐ F6 关闭有未保存改动的标签
- **操作**：再改一行不保存 → 点标签上的 ✕
- **预期**：弹「有未保存的改动」，三个按钮：取消（留着）/ 丢弃（关掉不保存）/ 保存并关闭

### ☐ F7 窗口拖动、缩放、最大化、最小化
- **操作**：按住编辑器顶栏空白处拖动（试试拖到左边 AI 聊天区上方）→ 拖右下角三角缩放 → 点顶栏「最大化」再点一次还原 → 点「最小化」→ 屏幕底部中间出现「📝 编辑器 · 1 个文件」小标签 → 点它
- **预期**：都能动；最小化后终端窗格不被遮挡；点小标签窗口回来

### ☐ F8 语法高亮
- **操作**：双击打开 `check.md` 和 `a.py`
- **预期**：.md 的标题、.py 的 `print` 有颜色；`case1.txt` 故意不着色（它是 TC 脚本不是 shell）
- **附加**：切换 DSH 明 / 暗主题，编辑器配色跟着变

### ☐ F9 TC 编号徽章
- **操作**：看两个终端窗格的标题条和右侧「活跃会话」列表
- **预期**：mock-1 显示 `TC0`、mock-2 显示 `TC1`（两处一致）
- **操作**：在活跃会话列表里把 mock-2 拖到 mock-1 上面
- **预期**：编号互换：mock-2 变 TC0、mock-1 变 TC1（拖动 = 换编号）。**测完拖回去**
- **操作**：断开 mock-2 再重连
- **预期**：断开时它不占编号；重连后回到 TC1

### ☐ F10 执行整份脚本
- **操作**：编辑器切到 case1.txt → 点底栏绿色「▶ 执行脚本」
- **预期**：弹「确认 TC 编号映射」：`TC0 mock-1 3 条`、`TC1 mock-2 3 条`、`TC5 — ✗ 无对应在线终端（1 条将跳过）`，下面黄字提示「第 6 行：间隔1s再发」；按钮写「确认执行（6）」
- **操作**：点确认
- **预期**：两台终端里命令一条条出现（窗格边框闪一下）；编辑器底部出现汇总条：`✓ 6  ✗ 1`，逐条列出 `TC0 mock-1: show version quiet` 等，最后一条 `TC5: show run 无对应在线终端`；屏幕底部弹「执行 case1.txt：成功 6 / 失败 1」；汇总条不会自己消失，点右上 ✕ 才关

### ☐ F11 本次会话不再确认
- **操作**：再点「执行脚本」→ 勾「本次会话不再确认」→ 确认 → 第三次点「执行脚本」
- **预期**：第三次不弹确认框直接执行；刷新页面后再执行又会弹

### ☐ F12 右键「执行选中脚本」
- **操作**：在编辑器里用鼠标选中第 10、11 两行（`show interfaces` 和 `###echo…`）→ 右键 → 「▶ 执行选中脚本」→ 确认
- **预期**：确认框只有 `TC1 mock-2 2 条`（目标继承了上面的 `##>1`）；只有 mock-2 收到这两条，其中 `###echo 可发送注释` 整行原样发出

### ☐ F13 右键「执行本节」
- **操作**：把光标点在第 3 行（`show version`）→ 右键 → 「▶ 执行本节」
- **预期**：确认框标题含 `[基础信息]`，只有第一节的 4 条（3 条给 TC0、1 条 show clock 给 TC0 和 TC1）

### ☐ F14 发送选中（非脚本文件）
- **操作**：切到 check.md → 选中最后两行 → 点底栏「发送选中 →」
- **预期**：弹「发送选中内容到终端」，列出 mock-1 / mock-2 带 TC 徽章，默认只勾 TC0，按钮写「发送（1）」
- **操作**：把 mock-2 也勾上 → 发送（2）
- **预期**：两台终端都收到 `- show version`、`- show clock` 两行；汇总条显示 4 条 ✓

### ☐ F15 按钮可用性
- **操作**：依次切到 check.md、a.py、case1.txt，看底栏
- **预期**：check.md：「执行脚本」灰、「发送选中」可点；a.py：两个都灰（悬停有说明）；case1.txt：两个都可点；「上传」永远灰（下一迭代做）

### ☐ F16 超时处理（可选）
- **操作**：右侧连接面板编辑 mock-1 的「连接选项」：静默期改 5000、超时改 1000（让每条都超时）→ 保存并重连 → 执行 case1.txt
- **预期**：第一条发完 1 秒后弹「命令超时」框，两个按钮「中止剩余」「跳过，继续下一条」；点跳过继续，后面每条都会问；点中止剩余，汇总条里剩下的标「已中止」。**测完把参数改回默认**

### ☐ F17 越界保护
- **操作**：编辑器里保持 case1.txt 打开 → 文件面板「换目录」切到别的目录（比如 `D:\`）→ 回编辑器改一行 → Ctrl+S
- **预期**：保存失败，提示「路径在当前文件树根之外」；文件没被改动。**测完切回 `D:\tc-test`**

### ☐ F18 大文件只读（可选）
- **操作**：PowerShell 里 `fsutil file createnew D:\tc-test\big.txt 11000000` 造一个 11MB 文件 → 双击打开
- **预期**：编辑器顶部黄条「文件超过 10MB，只显示前 10MB，只读」；不能输入；「保存」灰
