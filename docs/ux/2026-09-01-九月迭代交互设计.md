## 1. 用户与场景上下文

### 1.1 产品形态
DSH（DeepSeek Harness）插件，浏览器内运行。host 半（Node.js）+ 浏览器半（React 18）。内网环境，桌面端为主。

### 1.2 目标用户
芯片/设备验证工程师，同时操作多台被测设备（DUT），需要：
- 在多台终端上批量执行验证脚本（TC 脚本）
- 编辑本地配置文件、脚本
- 把本地文件推到设备、把设备日志拉回来
- 与 AI Agent 协作（AI 调 tm_* 工具，人实时共视）

### 1.3 核心场景（本迭代新增）
| 编号 | 场景 | 用户目标 |
|---|---|---|
| NS1 | 执行 TC 验证脚本 | 把 case1.txt 里的命令按 TC 编号映射逐条打到对应终端，汇总结果 |
| NS2 | 选中发送 | 把 .md/.txt 里选中的若干行发到指定终端 |
| NS3 | 编辑本地文件 | 双击本地文件 → 编辑 → 保存 |
| NS4 | 上传文件到设备 | 本地文件 → 远端当前目录 |
| NS5 | 从设备下载文件 | 远端文件 → 本地保存（仅下载按钮，双击不下载） |
| NS6 | 浏览远端目录 | 切终端、上一级、面包屑跳转、刷新 |

### 1.4 设备约束
桌面端键鼠为主；触控目标 ≥ 44×44px（后续移动端适配时）；键盘可达性需保证。

## 3. 任务流设计

### 3.1 流程 A：TC 脚本执行

```
[本地文件面板 双击 case1.txt]
  → 编辑器新开 Tab（若已开则切到该 Tab）
  → 用户查看/编辑脚本
  → 点 [▶ 执行脚本]（底部按钮）
  → 前端解析脚本：tc-parser.ts → [{port:'*'|'0'|'1'..., cmd}]
  → 前端算映射：tcMap = activeOrder.map((sid,i) => [i, sid])
  → ⚠️ **冻结映射快照**：执行期间不随会话断线/重连重算（防 mid 执行编号漂移打到错终端）
  → 弹【TC 映射确认框】
     ├─ 列出每条命令将发往哪些终端（TC0→dut-ssh-22，*: →全部）
     ├─ 提供"本次会话不再确认"勾选
     └─ 用户：取消 → 回编辑器 / 确认 → 继续
  → 逐条发送：对每条命令，按 port 找目标 sessionId 列表
     ├─ port='*' → 全部在线终端
     └─ port='N' → tcMap[N]，无对应 → 汇总标 ✗
  → 每条命令经 sendAndWait 打到对应终端窗格（人机共视，窗格闪烁）
  → 全部完成 → 编辑器底部滑出【汇总条】
     ├─ 逐端口 ✓/✗/waitReason
     └─ ✗ 含原因（无对应终端/超时/断线/语法错误）
```

**解析失败处理（B7）**：tc-parser 遇到无法识别的行（如 `x: cmd` 中 x 非数字非 `*`）→ 汇总条标"⚠ 第 N 行语法错误，已跳过"，其余正常行继续执行；整脚本无任何可执行行 → 弹"脚本无可执行命令"不执行。

**选中执行**：编辑器内选中若干行 → 右键「▶ 执行选中脚本」→ 只解析选中行 → 同上流程（确认框 + 逐条 + 汇总）。

**"本次会话不再确认"**：勾选后，当前浏览器会话内再执行脚本不弹确认框（刷新页面/重开工作区后恢复）。不落盘。

### 3.2 流程 B：选中发送

```
[编辑器打开 .md 或 .txt]
  → 用户选中若干行
  → 点 [▶ 发送选中→] 或 右键「发送选中到终端…」
  → 弹【发送选中弹窗】
     ├─ 列出全部在线终端（复选框）
     ├─ 默认勾选当前激活终端
     ├─ 实时显示"发送(N)"，N=勾选数
     └─ N=0 时发送按钮禁用
  → 确认 → 逐条发送：每条走 sendAndWait
     ├─ 上一条完成（或超时，提示可跳过）再发下一条
     └─ 命令出现在勾选终端窗格（人机共视）
  → 完成 → toast 汇总"成功 N / 超时 M"
```

**行数过多策略（B3）**：选中行数 > 20 时，发送弹窗顶部提示"⚠ 选中 N 行，逐条发送预计约 M 秒（每条等静默 500ms+），确认继续？"。不硬性限制行数，但让用户知情。超时行可跳过（弹窗提供"跳过超时项继续"按钮）。

**行数过多策略（B3）**：选中行数 > 20 时，发送弹窗顶部提示"⚠ 选中 N 行，逐条发送预计约 M 秒（每条等静默 500ms+），确认继续？"。不硬性限制行数，但让用户知情。超时行可跳过（弹窗提供"跳过超时项继续"按钮）。

**按钮可用性矩阵（D5）**：

| 文件类型 | [▶ 执行脚本] | [▶ 发送选中→] | [📤 上传] |
|---|---|---|---|
| `.txt`（TC 脚本） | 可用 | 可用 | 可用 |
| `.md` | 禁用 + tooltip"仅 TC 脚本(.txt)可执行" | 可用 | 可用 |
| `.csv`/`.sh`/`.py`/`.json`/`.ini` | 禁用 | 禁用 + tooltip"仅 .md/.txt 支持发送选中" | 可用 |
| 其他纯文本 | 禁用 | 禁用 | 可用 |

> `.txt` 两个按钮都可用（双按钮常驻，用户自选语义），与设计方案 2.5 一致。

### 3.3 流程 C：文件上传 / 下载

**上传（本地 → 远端）**：
```
[本地文件面板：单击选中本地文件/文件夹]
  → 点 [📤 上传文件] 或 [📁 上传文件夹]
  → 校验：本地已选中 + 类型匹配（文件/文件夹）
  → 远端面板当前目录作为目标（A4：即使远端面板收起，其当前目录状态仍保持——初始=各会话 home/root，展开过则记忆最后目录）
  → 同名检查（A3）：目标已存在同名 → 弹"覆盖/跳过/重命名"，默认"跳过"防误覆盖
  → SFTP put（SSH）/ base64 模拟（Telnet，标实验性）
  → 面板内对应行显示进度条（替换大小文字）
  → 完成：toast"X 已上传到 Y" + 远端列表刷新
  → 失败：toast 错误 + 行内红色标记
```

> **两个上传入口**（§11.1 已确认）：
> - ① **本地面板上传** = 本地选中 → 远端（上图流程，联动，需本地有选中）
> - ② **远端面板上传** = 触发浏览器文件选择对话框 → 远端（自包含，不依赖本地面板，见 §6.3）
> - 两者目标都是远端当前目录，同名检查（A3）均生效

**下载（远端 → 本地浏览器保存）**：
```
[远端文件面板：单击选中远端文件/文件夹]
  → 点 [📥 下载文件] 或 [🗂️ 下载文件夹]
  → 校验：远端已选中 + 类型匹配
  → SFTP get → 流式响应（content-disposition 触发浏览器保存）
  → 面板内行内进度条
  → 完成：toast"X 已下载"
```

> **远端文件双击 = 无操作**（D6，用户决策）。远端文件只能单击选中，下载必须用下载按钮。远端文件不进编辑器。

**进度反馈（D7）**：
- 开始：toast"开始上传/下载 X"
- 进行中：面板内对应行显示进度条（百分比，200ms 节流更新）
- 完成：toast 汇总"X 已上传/下载完成（N 字节，用时 M 秒）"
- 失败：toast 错误码 + 面板行红色标记 + 重试按钮

### 3.4 流程 D：本地文件编辑

```
[本地文件面板：双击本地文件]
  → 编辑器新开 Tab
  → host 半 files.read 读文件内容
  → CodeMirror 渲染（按扩展名选语法高亮）
  → 用户编辑 → 输入即置脏（Tab 显示未保存圆点）
  → Ctrl+S → host 半 files.write 原子写 → 清脏标记 → toast"已保存"
```

> 编辑器**仅编辑本地文件**。远端文件不进编辑器（用户决策）。

### 3.5 流程 E：Agent 联动（现有，不动）

AI 调 tm_connect/tm_send → 终端窗格同步显示（人机共视）。tm_upload/tm_download 随模块三交付。本迭代不改动既有 AI 工具交互。

### 4.3 层级约束
- 每层导航不超过 7 项（米勒法则）：文件面板工具栏 6 按钮 + 换目录 = 7，达标
- 用户当前位置始终可见：文件面板面包屑、编辑器 Tab 标题
- 深层内容提供返回：编辑器最小化成底部标签（不丢失）、文件面板收起条（不丢失）

| TC 脚本语法错误 | 汇总条"⚠ 第 N 行语法错误，已跳过" | 检查脚本格式 | 其余行继续 |
| 同名文件冲突 | 弹"覆盖/跳过/重命名" | 默认跳过防误覆盖 | 用户选择 |

**文案原则**：说明发生了什么 + 为什么 + 怎么修复，禁用指责性文案（不用"你错了"，用"路径越界"）。

### 8.4 状态可追溯
- 用户始终知道"我在哪"：文件面板面包屑、编辑器 Tab 标题、终端窗格名称
- 用户始终知道"发生了什么"：toast、汇总条、行内进度
- 用户始终知道"下一步去哪"：汇总条完成后可关、toast 完成后无强制跳转

## 11. 与设计方案的差异说明

以下是我基于交互清晰性做的调整，**已全部确认**：

### 11.1 远端面板"上传"按钮的源（已确认采纳）

**决策**：远端面板"上传文件/文件夹"按钮 = **触发浏览器文件选择对话框** → 上传到远端当前目录（自包含，不依赖本地面板选中）。本地面板"上传"按钮保留"本地选中 → 远端"语义（需联动）。

**理由**：远端面板自包含降低认知负担（只展开远端面板也能上传）；本地面板上传保留联动给"已浏览本地树"的用户。已落实到 §6.3。

### 11.2 TC 徽章单终端时显示（已确认）

**决策**：在线会话 ≥1 即显示 TC0（含单终端），因为 TC 脚本里 `0:` 指定编号，单终端时用户需知道当前是 TC0。单终端时拖动手柄禁用（无排序意义）。已落实到 §6.1/6.2。

### 11.3 汇总条常驻不自动消失（已确认）

**决策**：执行脚本后汇总条常驻，手动关闭。理由：验证场景需复盘结果，自动消失会丢失信息。已落实到 §6.5。

### 11.4 远端文件不编辑（已确认）

用户决策：**不做编辑远端文件**。编辑器仅编辑本地文件。远端文件只能：浏览（面板）、下载到浏览器保存（下载按钮）、被本地上传覆盖。此决策已落实到 §0 D6、§2.4、§3.3、§3.4、§5.2、§5.3、§6.3、§6.5。
