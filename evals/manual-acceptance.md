# 人工验收清单

本文件是**唯一**的人工验收清单（原 `docs/test-plan.zh.md` 的脚手架指令已随测试补全完成而废弃，重复项并入本页）。照着逐条跑，每条勾上。跑完 = MVP 全功能人工验证通过。

## 前置准备

```sh
# 1. 起两台模拟设备
cd /d/myProject/dsh/terminal-manager
node scripts/mock-device.mjs 2323 &
node scripts/mock-device.mjs 2324 &

# 2. 起 DSH
cd /d/myProject/dsh/deepseek-harness
pnpm dsh --profile tm-dev --port 4580 --no-open &
# 浏览器开 http://127.0.0.1:4580，硬刷新（Ctrl+F5）加载最新 client.js
```

## 组一：配置管理

### ☐ S1 新建连接（保存）
- **操作**：点侧边栏底部「🖥️ 终端管理」→ 工作区打开 → 右侧「连接」面板 → 协议选 **Telnet** → 填 名称`mock-1`、主机`127.0.0.1`、端口`2323` → 点「保存」
- **预期**：不报错；「收藏」出现 mock-1

### ☐ S1-临时连接（不入库）
- **操作**：不点保存，直接点「连接」按钮
- **预期**：终端窗格出现，显示横幅 `Mock Router :2323`

### ☐ S12 编辑连接
- **操作**：点「最近连接」里的 mock-1 卡片 → 表单回填 → 改名称为 `mock-1-renamed` → 点「保存」
- **预期**：列表里名字变成 mock-1-renamed
- 注：编辑后想取消，点「取消」按钮（已加）

### ☐ S12 删除连接
- **操作**：右键 mock-1 卡片 → 删除
- **预期**：从列表消失

## 组二：连接与观察

### ☐ S2 一键连接
- **操作**：新建/选中一条 2323 的连接 → 点「连接」
- **预期**：状态点变绿（已连接）；终端窗格出现，显示横幅 + `router> ` 提示符

### ☐ S3 多设备同屏
- **操作**：再连一台 2324（名称 mock-2）
- **预期**：两个终端窗格并排（或随宽度自动换列），都在线；窗格填满终端模块、无空隙

### ☐ S13 隐藏/显示窗格
- **操作**：点「活跃会话」里某条会话条目
- **预期**：该窗格隐藏（连接不断，条目变灰）；再点回来恢复

### ☐ S14 多终端最大化
- N/A：当前版本无最大化按钮（待办，见 `plan.md` 后续待办）

## 组三：手动操作

### ☐ S4 手动敲命令
- **操作**：在某个终端窗格里直接敲 `show version` 回车
- **预期**：能看到自己敲的字（设备回显）；回车后显示 `MockOS Version 1.0.4`
- 注：退格在输入行空了之后不再删提示符（已修）

### ☐ S5 广播到全部
- **操作**：底部广播栏（两行布局）输入 `show version` → 目标选「全部」→ 点「发送」
- **预期**：两个终端同时回显命令 + 版本输出

### ☐ S6 广播到部分
- **操作**：取消选一个芯片（只留一个目标）→ 发送
- **预期**：只有选中的那台回显

## 组四：AI 自动化（核心价值）

### ☐ S7 AI 单机测试
- **操作**：在聊天框发：`连上 127.0.0.1:2323 跑 show version 告诉我结果`
- **预期**：AI 调 tm_connect + tm_send，回复含 `MockOS Version 1.0.4`

### ☐ S10 人机共视
- **操作**：S7 跑的时候，同时看终端工作区
- **预期**：AI 连的会话出现在网格里，能看到设备回显
- 已知限制：AI 敲命令的「击键过程」不一定可见（取决于设备回显/localEcho，待办）

### ☐ S8 AI 批量测试
- **操作**：发：`连上 127.0.0.1:2323 和 2324，都跑 show version，汇总`
- **预期**：AI 用 tm_send_all 或两次 tm_send，汇报两台版本

### ☐ S9 AI 读现场
- **操作**：发：`连上 127.0.0.1:2323，告诉我当前屏幕显示什么`
- **预期**：AI 调 tm_read，描述横幅 `Mock Router`

## 组五：异常

### ☐ S11 地址不通
- **操作**：新建连接 主机`127.0.0.1` 端口`9999` → 点「连接」
- **预期**：报错（HOST_UNREACHABLE 或 CONN_TIMEOUT），不卡死

### ☐ S11 设备掉线
- **操作**：连上 2323 → 在终端里敲 `exit`（模拟设备会断开）
- **预期**：终端窗格消失/标记断开；状态点变灰

### ☐ S11 命令守卫（AI 路径）
- **操作**：发：`连上 127.0.0.1:2323 跑 rm -rf /`
- **预期**：AI 调 tm_send 被拦（COMMAND_BLOCKED），AI 告诉你命令被安全策略拦截

## 组六：布局与主题

### ☐ 拖动分隔条
- **操作**：拖聊天和终端之间的竖条，左拖/右拖
- **预期**：聊天变窄/终端变宽（或反之），实时跟随；松手定住；最左聊天收窄到 300，最右聊天拉到动态上限（大屏可收很窄）

### ☐ 关闭还原
- **操作**：点「✕ 关闭」关掉终端工作区
- **预期**：聊天恢复原来宽度（已修）

### ☐ 重新打开
- **操作**：再点「终端管理」
- **预期**：工作区重新出现；之前连的会话还在（如果没断）

### ☐ 字段悬停提示
- **操作**：鼠标悬停在「回显」「换行」「握手超时」等 label 上
- **预期**：显示中文说明（回显：设备不回显时开，否则双字符）
