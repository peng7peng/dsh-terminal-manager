# M1 界面选型结论（定稿记录）

- 日期：2026-08-26
- 基准原型：`prototypes/full-view-bc.html`（B 卡片式 + C 状态中枢混搭版）
- 状态：**已定稿**，M4 真界面以此为视觉与交互基准

## 选定风格

**B（明亮卡片）的外壳 + C（状态中枢）的结构**，双半包布局细节如下。

## 布局

- 页签栏固定在最上方：「终端」（带会话数徽标，第一个）｜「连接」。
- **状态中枢条只在「终端」页签内显示**（卡片样式，不作为全局条）。
- 终端页签内自上而下：状态条 → 终端卡片网格 → 广播栏。
- 连接页签：卡片网格 + 新建/编辑表单。
- 配色实现时**自动跟随 DSH 明暗主题**（原型里的日/夜切换仅为演示）。

## 状态条交互（重要约定）

- 芯片**点选 = 显示/隐藏**该设备的终端窗格；**连接保持不断**，可随时恢复。
- **断开连接只由显式 ✕ 按钮完成**，不绑定在芯片点击上（防止生产设备误触）。
- 呼吸灯改为**静态常亮**（不做闪烁动画，避免视觉跳动导致误触）。
- **不显示「已隐藏 n」计数**。
- 隐藏的终端仍然在线，仍可作为广播目标被选中。

## 终端网格

- 卡片式终端，自适应网格 + 滚动。
- 每格标题条有 **⛶ 最大化/还原**（终端多于 3 个时的聚焦手段）。

## 广播栏

- 「全部」为全选/全不选总开关；各会话芯片**可单独点选**进出广播范围。
- 发送按钮显示目标计数（如「发送（3）」）。

## 连接表单：必填 / 选填

- 通用必填：名称\*、IP\*；端口带默认值（SSH 22 / Telnet 23），留空用默认。
- **SSH**：用户名\*；认证方式\*（密码/密钥二选一）——选密码则密码\*，选密钥则私钥\*、口令选填。
- **Telnet**：用户名、密码均选填。
- 备注：选填。
- 保存时校验必填项：红框 + 提示语。
- 点击表单外空白处 = 取消。

## 面板行为

- 侧边栏入口按钮：点击开/关整个工作区面板（宿主布局让位）。
