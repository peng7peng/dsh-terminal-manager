# 人工测试文件

把本地文件面板的根目录「换目录」到这个文件夹（`evals/manual-files`），逐个双击，对照下表看效果。

> 里面的地址、账号都是编的（10.0.x.x / user1 / pass1），不是真实设备。

| 文件 | 双击后 | 你应该看到 |
|---|---|---|
| `tc-sample.txt` | 编辑器打开（TC 脚本，**故意不着色**） | 真实样例的脱敏版，结构原样：`[标题]`、`##>0` / `##>12` / `##>012` 切目标、`##` 注释、`###` 可发送注释、多行 `call()` 函数、`##>01` 后紧跟空行、`##间隔…再发` 提示。点「执行脚本」看确认框：TC0/1/2 各多少条、没连的编号标 ✗、间隔提示列出来 |
| `case1.txt` | 编辑器打开 | 13 行小脚本，连两台 mock 后「执行脚本」应得到 ✓6 ✗1（`##>5` 没有对应终端） |
| `check.md` | 编辑器打开（Markdown 高亮） | 「执行脚本」灰、「发送选中」可点：选中最后两行发送 |
| `run.py` | 编辑器打开（Python 高亮） | 关键字 / 字符串 / 注释有颜色；两个底栏按钮都灰 |
| `deploy.sh` | 编辑器打开（Shell 高亮） | 同上 |
| `config.json` | 编辑器打开（JSON 高亮） | 键 / 值有颜色 |
| `settings.ini` | 编辑器打开（纯文本） | 不着色，可编辑保存 |
| `data.csv` | 编辑器打开（纯文本） | 不着色 |
| `notes.log` | 编辑器打开（纯文本） | 不着色 |
| `sample.xlsx` | **不进编辑器**，交给系统默认程序（Excel / WPS） | 列表里图标是 📎；双击后底部提示「已交给系统默认程序打开：sample.xlsx」，Excel 弹出来。右键也有「用系统默认程序打开」 |

## 想测大文件只读

PowerShell 里造一个 11MB 的文件再双击：

```powershell
fsutil file createnew D:\myProject\dsh\dsh-terminal-manager\evals\manual-files\big.txt 11000000
```

预期：编辑器顶部黄条「文件超过 10MB，只显示前 10MB，只读」。测完删掉（这个文件已在 .gitignore）。
