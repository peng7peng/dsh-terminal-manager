# 界面原型演示流程

- **原型文件：** `prototypes/ui-prototype-v1.html`
- **打开方式：** 浏览器直接打开（假数据，可交互）
- **目的：** 演示给用户看，确认交互设计是否符合要求

---

## 演示前说明

原型模拟 DSH 三栏布局（侧栏 | AI 聊天区 | 插件覆盖层工作区），含 9 月新增能力。数据均为假数据，交互可操作。

**视觉风格**：深色主题（贴近 DSH 实际），右上角可切换浅色。

**技术约束已确认**：
- 浮动编辑器 `position: fixed` 于视口，可拖到 AI 聊天区上方，不挡 AI 操作（DSH overlayLayer pointer-events 机制支持）
- 不被 DSH frame overflow 裁剪（frame 无 transform）
- z-index 与 DSH 全局 modal 的层级属联调项，原型内暂不处理

---

## 4 个演示场景

### 场景 1：TC 脚本执行（主流程）

**动线**：
1. 点「📁 本地文件」收起条展开面板
2. 双击 `case1.txt` → 浮动编辑器打开（新 Tab）
3. 查看脚本内容（含 `*:`/`0:`/`1:` 语法行）
4. 点底部 [▶ 执行脚本] → 弹 TC 映射确认框
5. 核对映射（TC0→dut-ssh-22，TC1→dut-ssh-2222…）
6. 点 [▶ 确认执行] → 终端窗格逐条显示命令（闪烁）+ 编辑器底部滑出汇总条
7. 汇总条显示逐端口 ✓/✗

**展示要点**：
- TC 编号徽章常驻显示在终端窗格 + 活跃会话列表
- 映射确认框防误执行
- 人机共视：命令真的"打"进终端窗格

### 场景 2：选中发送

**动线**：
1. 编辑器切到 `check.md` Tab（或双击本地面板 check.md）
2. 选中若干行（原型预置选中 3 行）
3. 点底部 [▶ 发送选中 →] → 弹发送选中弹窗
4. 勾选目标终端（实时显示"发送(N)"）
5. 点 [发送] → 终端窗格逐条显示 + toast 汇总

**展示要点**：
- 按钮可用性矩阵：.md 只有 [发送选中] 可用，[执行脚本] 禁用
- 弹窗实时显示发送数量防误

### 场景 3：文件上传

**动线**：
1. 展开本地文件面板，单击选中 `config.csv`
2. 展开远端文件面板（确认目标目录）
3. 点本地面板 [📤 上传文件] → 行内进度条 → toast"已上传"

**展示要点**：
- 两个上传入口：本地面板（联动）/ 远端面板（自包含，触发文件选择对话框）
- 进度反馈：行内进度条 + toast 汇总
- 同名检查（A3）：若远端已存在同名，弹"覆盖/跳过/重命名"

### 场景 4：浮动编辑器窗口控制

**动线**：
1. 拖动编辑器标题条 → 移到 AI 聊天区上方（不挡 AI 输入框）
2. 点 🗕 最小化 → 收成底部标签
3. 点底部标签 → 还原
4. 点 🗗 最大化 → 铺满视口
5. 拖右下角 → 缩放

**展示要点**：
- 浮窗 fixed 视口，可拖到任意位置
- 最小化不丢失，底部标签还原
- AI 聊天区仍可操作（pointer-events 机制）

### 附加：会话拖动排序

**动线**：
1. 在连接面板「活跃会话」拖动某会话项
2. 放下 → TC 编号跟随重排 → 所有终端窗格徽章实时更新 → toast 提示

**展示要点**：
- TC 编号 = 会话顺序（D1）
- 拖动即切换编号
- 置顶不影响编号（B2）
